# 个股研究模块

本模块用于单独分析每只股票的商业逻辑、估值、业绩、风险和操作条件。个股研究可以引用主线评级，但不能用“属于强主线”替代公司自身研究。

## 1. 模块目标

回答七个问题：

1. 这家公司是否值得纳入持仓或观察池？
2. 它的核心商业逻辑是什么？
3. 当前估值是否有赔率？
4. 业绩趋势是否验证投资逻辑？
5. 所属主线是否支持它进入进攻仓？
6. 当前适合买入、持有、加仓、减仓、卖出，还是观察？
7. 触发操作变化的条件是什么？

本模块输出的是单只股票档案，不直接生成组合级买卖清单。

## 2. 股票仓位角色

| 角色 | 定义 | 仓位含义 |
| --- | --- | --- |
| 长期核心股 | 商业模式、竞争优势和业绩确定性较强 | 可作为长期持仓，但仍受单股上限约束 |
| 主线进攻股 | 属于 A 档主线，趋势和资金强，弹性高 | 可进入进攻仓，但必须有失效条件 |
| 波段交易股 | 基于趋势、催化或估值修复的阶段性机会 | 必须有明确买卖条件 |
| 主题试错股 | 主题弹性大但持续性不确定 | 只能小仓试错 |
| 观察股 | 逻辑未确认或价格不合适 | 不买入，只跟踪 |
| 回避股 | 逻辑、估值、财务或风险不匹配 | 不配置 |

原则：

- 单一个股一般不超过总资产的 8%-12%。
- 主题试错股不超过主题仓边界。
- 任何个股买入都必须有买入理由、估值区间、失效条件和减仓条件。

## 3. 个股评分框架

每只股票按 100 分评分：

```text
商业逻辑20
+ 行业/主线匹配15
+ 财务质量15
+ 业绩趋势15
+ 估值赔率15
+ 趋势与资金10
+ 风险可控性10
- 个股风险惩罚0~30
```

最终个股分数：

```text
个股分数 = 基础分 - 个股风险惩罚
```

评级参考：

| 个股分数 | 建议评级 | 含义 |
| ---: | --- | --- |
| 80-100 | A | 高质量候选，可作为重点持仓或主线进攻股 |
| 65-79 | B | 可以配置或持有，但需控制仓位 |
| 50-64 | C | 观察或小仓试错 |
| 0-49 | D | 回避或等待修复 |

注意：

- 分数高不等于立刻买入，还要看市场仓位、主线评级、当前组合和触发条件。
- 个股风险惩罚最高 30 分，因为个股黑天鹅、财务、治理和估值杀伤力高于 ETF。

## 4. 分项评分细则

### 4.1 商业逻辑 20 分

观察对象：

- 公司业务是否清晰
- 护城河或竞争优势
- 产品或服务需求是否真实
- 增长空间和盈利模式
- 是否过度依赖单一客户、单一产品或补贴

打分参考：

| 状态 | 分数 |
| --- | ---: |
| 逻辑弱或主要靠概念 | 0-5 |
| 有业务基础但优势不清 | 6-10 |
| 逻辑清晰，具备一定竞争力 | 11-15 |
| 商业模式优秀，竞争优势明确 | 16-20 |

### 4.2 行业/主线匹配 15 分

观察对象：

- 所属行业景气度
- 是否属于 A/B/C/D 档主线
- 公司是否是主线中的龙头、中军、弹性股或补涨股
- 是否真正受益，而不是蹭概念

打分参考：

| 状态 | 分数 |
| --- | ---: |
| 不在有效主线，或仅蹭概念 | 0-4 |
| 属于 C/D 档主题或弱行业 | 5-8 |
| 属于 B 档主线或景气修复行业 | 9-12 |
| 属于 A 档主线且是核心受益公司 | 13-15 |

### 4.3 财务质量 15 分

观察对象：

- 毛利率和净利率
- ROE/ROIC
- 现金流
- 资产负债率
- 应收账款和存货
- 商誉、减值和资本开支压力

打分参考：

| 状态 | 分数 |
| --- | ---: |
| 财务质量差，风险明显 | 0-4 |
| 财务质量一般，有明显短板 | 5-8 |
| 财务较稳健 | 9-12 |
| 财务质量优秀，现金流和回报率好 | 13-15 |

### 4.4 业绩趋势 15 分

观察对象：

- 营收和利润增速
- 盈利预期是否上修
- 订单、价格、出货、毛利率变化
- 财报是否验证主线逻辑
- 是否存在业绩低于预期风险

打分参考：

| 状态 | 分数 |
| --- | ---: |
| 业绩下滑或明显不及预期 | 0-4 |
| 业绩平淡，缺少验证 | 5-8 |
| 业绩边际改善 | 9-12 |
| 业绩趋势明确向上，预期上修 | 13-15 |

### 4.5 估值赔率 15 分

观察对象：

- PE/PB/PS/EV 等估值
- 历史估值分位
- 与同行比较
- 与盈利增速匹配度
- 下行空间和上行空间

打分参考：

| 状态 | 分数 |
| --- | ---: |
| 估值高，赔率差 | 0-4 |
| 估值中性偏贵 | 5-8 |
| 估值合理或略便宜 | 9-12 |
| 估值低且基本面未恶化，赔率好 | 13-15 |

### 4.6 趋势与资金 10 分

观察对象：

- 股价是否站上关键均线
- 相对行业和指数强弱
- 成交量是否健康
- 机构、北向或重要资金参与痕迹
- 是否高位放量滞涨

打分参考：

| 状态 | 分数 |
| --- | ---: |
| 趋势向下，资金流出 | 0-3 |
| 横盘震荡，方向不明 | 4-6 |
| 趋势修复，资金回流 | 7-8 |
| 趋势向上，资金持续强化 | 9-10 |

### 4.7 风险可控性 10 分

观察对象：

- 财务风险
- 治理风险
- 政策或监管风险
- 客户集中风险
- 供应链风险
- 竞争恶化风险
- 流动性和波动风险

打分参考：

| 状态 | 分数 |
| --- | ---: |
| 风险高且不可控 | 0-3 |
| 风险较多，需要明显折价 | 4-6 |
| 风险可识别且可管理 | 7-8 |
| 风险较低，边界清晰 | 9-10 |

## 5. 个股风险惩罚 0-30 分

观察对象：

- 财务造假、审计、监管或治理风险
- 业绩大幅不及预期
- 估值极高且缺少业绩验证
- 高位放量滞涨
- 大股东减持、质押或关联交易风险
- 客户或供应商过度集中
- 技术路线被替代
- 行业价格战恶化
- 流动性不足
- 个股与组合已有持仓高度重叠

打分参考：

| 风险状态 | 扣分 |
| --- | ---: |
| 风险较低 | 0-5 |
| 有局部风险 | 6-10 |
| 风险明显，需要折价或控仓 | 11-18 |
| 高风险，不宜新增 | 19-24 |
| 极高风险，优先回避或卖出 | 25-30 |

## 6. 操作评级

| 操作评级 | 含义 |
| --- | --- |
| Buy | 可买入，但仍需满足市场仓位、主线和组合约束 |
| Add | 可加仓，通常要求已有仓位且触发加仓条件 |
| Hold | 持有，不新增 |
| Reduce | 减仓，降低风险或兑现收益 |
| Sell | 卖出或清理 |
| Watch | 观察，等待条件 |

操作评级必须包含：

- 买入理由
- 估值区间
- 目标仓位区间
- 加仓条件
- 减仓条件
- 卖出/失效条件

## 7. 长线与波段分离

同一只股票如果同时有长线逻辑和波段交易逻辑，必须分开写：

- 长线逻辑：基本面、估值、竞争优势、业绩周期。
- 波段逻辑：趋势、资金、催化、止损或止盈条件。

禁止把短线交易失败后改口成长期持有。

## 8. 仓位规则

- 普通个股单股上限：总资产 8%-12%。
- 高确定性长期核心股可申请更高上限，但必须单独说明理由。
- 主线进攻股合计受单一行业/主线上限约束。
- 主题试错股必须小仓，不能因上涨自动升级为主仓。
- 若所属主线降级，个股必须重新评估。

## 9. 输出口径

每只个股档案必须包含：

- 基本信息
- 仓位角色
- 所属主线和主线评级
- 商业逻辑
- 财务质量
- 业绩趋势
- 估值赔率
- 趋势与资金
- 风险惩罚
- 操作评级
- 目标仓位区间
- 买入条件
- 加仓条件
- 减仓条件
- 卖出/失效条件
- 下次更新触发条件

## 10. 与其他模块的关系

- 市场仓位模块决定个股仓位总环境。
- 主线研究模块决定主线进攻股是否有资格放大。
- ETF 研究模块帮助比较“买 ETF 还是买个股”。
- 组合分析模块决定单股集中度和行业暴露是否超标。
- 操作建议模块基于个股档案生成具体动作。

## 11. 使用提示词

日常使用时，可以对 Codex 说：

```text
请按 docs/modules/STOCK_RESEARCH.md 和 templates/stock_profile_template.md 分析这只股票。
必须引用最新市场仓位结论、主线登记册和已有 ETF/组合信息。
只更新个股档案，不直接生成组合买卖清单。
```
