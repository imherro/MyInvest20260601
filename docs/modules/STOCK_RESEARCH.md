# 个股研究模块

版本：v2.0

本模块用于生成可进入真实投资决策流程的单股研究报告。报告重点不是普通公司介绍，而是回答：这只股票的资产属性是什么、估值赔率是否成立、交易条件是否成熟、风险如何控制。

本模块输出的是单只股票的研究输入和条件化策略，不直接生成组合级买卖清单，不替代 `ACTION_PLAN`、`PORTFOLIO_ANALYSIS` 或市场仓位模块。

## 1. 强制前置：数据新鲜度

任何估值、技术面、资金流、仓位建议之前，必须先识别最近完整交易日，并校验高频交易数据是否新鲜。

规则：

- 以最近完整 A 股交易日为基准，不以自然日简单判断。
- `daily`、`daily_basic`、`moneyflow`、指数行情、同业估值等高频数据，原则上不得早于最近完整交易日超过 1 个交易日。
- `margin_detail`、`cyq_perf`、股东户数、北向或其他增强数据能取则取；取不到必须披露缺口，但不自动阻止基本面研究。
- 如果高频数据滞后超过 1 个交易日，报告顶部必须写明：

```text
【严重警告：行情/估值/资金数据过期，不得用于当前交易判断】
```

数据过期时：

- 年报、季报、主营构成、业务结构仍可使用。
- 当前股价、PE/PB/PS、市值、技术面、资金流、筹码、仓位建议必须降权或暂停。
- 不得输出确定性的“当前估值”“当前买点”“当前仓位建议”。
- 只能输出“截至某日期”的历史分析。

报告顶部必须输出：

| 数据模块 | 最新日期 | 距最近完整交易日差距 | 是否可用于当前判断 |
| --- | --- | ---: | --- |
| daily | 待填写 | 待填写 | 待填写 |
| daily_basic | 待填写 | 待填写 | 待填写 |
| moneyflow | 待填写 | 待填写 | 待填写 |
| margin_detail | 待填写 | 待填写 | 待填写 |
| cyq_perf | 待填写 | 待填写 | 待填写 |
| 财务报表 | 待填写 | 待填写 | 待填写 |
| 同业估值 | 待填写 | 待填写 | 待填写 |
| 指数/市场数据 | 待填写 | 待填写 | 待填写 |

报告还必须明确：

```text
本报告当前交易判断使用的价格日期为：YYYY-MM-DD
本报告财务判断使用的最新财报期为：YYYYQX 或 YYYY年报
```

## 2. 数据分类

报告必须区分两类数据。

A 类：低频基本面数据

- 年报、季报、主营构成、资产负债表、现金流、股东结构、业务描述、募投项目。
- 允许滞后至最近正式披露财报期。

B 类：高频交易数据

- 股价、市值、PE/PB/PS、成交额、换手率、资金流、融资融券、筹码、均线、相对强弱。
- 必须尽量更新至最近完整交易日。
- 如果 B 类数据过期，不得用旧价格计算当前估值或当前交易结论。

## 3. 资产分类

每只股票必须先判断资产属性。资产属性决定估值方法、交易条件和风险权重。

| 类型 | 典型标的 | 定价核心 |
| --- | --- | --- |
| 成长型产业公司 | AI、半导体、算力、创新药、机器人、高端制造 | 产业趋势、资金风格、盈利增速、估值 |
| 周期型/资源型/金融型 | 有色、煤炭、航运、钢铁、化工、券商、保险 | 行业景气、流动性、利率、估值 |
| 稳定价值/红利型 | 银行、公用事业、高股息央企、消费龙头 | 利率、分红、ROE稳定性、估值 |
| 题材投机型 | 业绩弱、情绪驱动标的 | 情绪、流动性、资金博弈 |
| 混合型资产 | 战略资源、平台型金融、周期成长交叉标的 | 拆分权重后分别判断 |

必须回答：

1. 这只股票本质是什么资产？
2. 市场真正愿意为它的什么能力付估值？
3. 当前应该用什么估值方法？
4. 哪些传统估值指标可能失效？哪些不能失效？

## 4. 个股评分框架

每只股票按 100 分评分：

```text
商业逻辑20
+ 行业/主线匹配15
+ 财务质量15
+ 业绩趋势15
+ 估值赔率15
+ 趋势与资金10
+ 风险可控性10
- 个股风险惩罚0~30
```

评级参考：

| 个股分数 | 建议评级 | 含义 |
| ---: | --- | --- |
| 80-100 | A | 高质量候选，可作为重点持仓或主线进攻股 |
| 65-79 | B | 可以配置或持有，但需控制仓位 |
| 50-64 | C | 观察或小仓试错 |
| 0-49 | D | 回避或等待修复 |

分数高不等于立刻买入，还必须满足市场仓位、主线评级、当前组合暴露和触发条件。

## 5. 估值与情景推演

估值不能只写“贵/便宜”，必须给出估值区间或估值锚。
个股档案应给出估值区间、估值锚和三情景推演，但不直接生成组合级买卖指令。最终买入、加仓、减仓、卖出动作由 ACTION_PLAN 结合市场仓位、组合暴露和盘中规则生成。
若需要每天或盘中使用的可视化估值分段，应另行生成 `research/valuations/valuation_*.md/json`，并同步写入 `research/alerts/intraday_rules.json`。

| 区间 | 股价范围 | 逻辑 |
| --- | ---: | --- |
| 极度低估区 | 待填写 | 待填写 |
| 合理区 | 待填写 | 待填写 |
| 偏高区 | 待填写 | 待填写 |
| 风险区 | 待填写 | 待填写 |
| 泡沫区 | 待填写 | 待填写 |

估值区间应结合：

- 当前股价、总市值、TTM 利润。
- 未来 1-2 年合理利润假设。
- 资产类型、同业估值、行业景气、利率和市场风格。
- 流通盘、资金结构和是否存在战略稀缺溢价。

禁止只用历史 PE 分位判断贵贱。上市时间短于 3 年时，历史估值分位只能作为弱参考。

必须做三情景推演：

| 情景 | 触发条件 | 核心假设 | 概率 | 对应市值/股价空间 | 主要风险 |
| --- | --- | --- | ---: | ---: | --- |
| 乐观 | 待填写 | 待填写 | 待填写 | 待填写 | 待填写 |
| 中性 | 待填写 | 待填写 | 待填写 | 待填写 | 待填写 |
| 悲观 | 待填写 | 待填写 | 待填写 | 待填写 | 待填写 |

如果数据不足以给出可靠目标价，必须说明“不足”，并改用估值锚和触发条件，不得制造伪精确。

## 6. 同业与估值锚

不能只看个股自身估值。应尽量建立三层比较：

1. 直接可比公司。
2. 同产业链公司。
3. 同资产属性公司。

输出表格：

| 公司 | 资产属性 | PE_TTM | PB | PS | ROE | 营收增速 | 净利增速 | 市值 | 估值合理性 |
| --- | --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | --- |

若直接可比公司不足，必须说明不足原因，并使用估值锚替代。

## 7. 财务质量

财务分析不能只列收入和利润。普通产业公司至少检查：

- 营收增长、净利润增长、扣非净利润。
- 毛利率、净利率、ROE/ROIC。
- 经营现金流、自由现金流。
- 应收账款、存货、资本开支。
- 资产负债率、净现金/有息负债。
- 一次性收益、现金流与利润匹配度。

金融、保险、银行、券商等特殊资产必须替换为适配指标：

- 保险：新业务价值、内含价值、营运利润、综合成本率、偿付能力、投资收益、分红。
- 银行：不良率、拨备覆盖率、净息差、核心一级资本充足率。
- 券商：经纪/投行/资管/自营结构、市场成交额敏感度、资本约束。

必须给一句话评级：

```text
财务质量：优秀 / 中性偏好 / 中性 / 中性偏差 / 较差。
```

## 8. 趋势、资金和关键价格

不能只写“低于 20/60 日线”。必须输出：

- 当前趋势阶段：底部区域、趋势突破、主升初期、主升中期、主升后期、高位震荡、弱修复、加速末期、崩塌初期。
- 短线支撑、中期支撑、趋势防守位、右侧确认位、风险压力位、前高压力位。
- 近 5/20/60 日资金流代理。
- 融资余额/流通市值、换手率、成交额、成交额趋势。
- 是否有散户 FOMO、机构抱团、量化趋势强化的迹象。证据不足时必须写“未确认”。

## 9. 市场风格适配

报告必须判断当前市场主风格：

- 科技成长、红利防御、周期资源、小票题材、金融权重、避险资产、混合风格。

必须回答：

1. 当前市场正在奖励什么资产？
2. 当前市场正在压制什么资产？
3. 该股票是否适配当前市场风格？
4. 如果风格切换，该股会获得增量资金，还是被资金抛弃？
5. 当前持有它的最大机会成本是什么？

## 10. 条件化操作策略

报告不能替代组合调仓，但必须给出可执行的个股级条件化策略。

| 动作 | 条件 |
| --- | --- |
| 观察 | 待填写 |
| 小仓试错 | 待填写 |
| 左侧低吸 | 待填写 |
| 右侧确认 | 待填写 |
| 加仓 | 待填写 |
| 减仓 | 待填写 |
| 止盈 | 待填写 |
| 止损/风控 | 待填写 |
| 回避 | 待填写 |

必须输出：

- 当前适合：重仓进攻 / 中仓配置 / 小仓试错 / 波段交易 / 观察等待 / 回避。
- 个股级建议仓位区间，作为后续组合模块输入，不是最终调仓指令。
- 是否适合核心仓长期持有。
- 当前更适合左侧布局、趋势跟随、回调低吸、高抛低吸，还是长期持有。
- 当前是否值得重仓：是 / 否 / 有条件。

即使操作评级是 `Watch`，也必须写清转为试错、右侧确认或回避的条件。

## 11. 风险排序和证伪条件

输出前五大风险：

| 风险名称 | 概率 | 影响程度 | 市场忽视程度 | 监控指标 | 应对方式 |
| --- | --- | --- | --- | --- | --- |

必须覆盖基本面、估值、行业或商品价格、资金结构、政策/监管/海外、技术趋势破坏等风险。

输出证伪条件：

| 证伪条件 | 类型 | 触发标准 | 影响 |
| --- | --- | --- | --- |

至少包括：

- 最关键证伪指标。
- 基本面失效条件。
- 行业景气失效条件。
- 估值体系失效条件。
- 技术趋势失效条件。
- 资金结构失效条件。

## 12. 数据质量评分

报告必须输出：

| 数据类别 | 完整度 | 新鲜度 | 可信度 | 是否影响结论 |
| --- | ---: | ---: | ---: | --- |
| 行情数据 | 待填写 | 待填写 | 待填写 | 待填写 |
| 估值数据 | 待填写 | 待填写 | 待填写 | 待填写 |
| 财务数据 | 待填写 | 待填写 | 待填写 | 待填写 |
| 资金流数据 | 待填写 | 待填写 | 待填写 | 待填写 |
| 同业数据 | 待填写 | 待填写 | 待填写 | 待填写 |
| 行业数据 | 待填写 | 待填写 | 待填写 | 待填写 |

数据质量总评：高 / 中高 / 中 / 中低 / 低。

若数据质量低于“中”，不得输出强买入、重仓、加仓等结论。

## 13. 最终结论格式

报告结尾必须输出：

1. 一句话核心结论。
2. 当前市场温度：0-100。
3. 风险等级：低 / 中 / 高。
4. 赔率：低 / 中 / 高。
5. 胜率：低 / 中 / 高。
6. 核心驱动力。
7. 最大风险。
8. 最大机会成本。
9. 最大证伪点。
10. 当前仓位建议。
11. 是否具备多倍潜力：是 / 否 / 有限。
12. 现在是否值得重仓：是 / 否 / 有条件。

## 14. 中国铀业特别规则

对于 `001280 中国铀业` 这类“战略资源 + 周期商品 + 次新低流通盘 + 央企平台”的混合资产，必须特别处理：

- 不能简单按普通有色周期股低 PE 逻辑估值。
- 不能因为战略资源稀缺就忽略 PE/PB/PS。
- 不能用上市不足 3 年的历史估值分位判断便宜。
- 必须拆分铀价驱动、核电长期需求、自产铀利润、外购铀贸易利润、国际贸易低毛利部分、共伴生矿想象空间、央企战略溢价、次新低流通盘资金溢价。
- 必须重点监控铀价、2026 中报利润增速、经营现金流、存货、融资余额/流通市值、是否站上 20/60 日线、是否放量突破前高、限售解禁和流通盘变化。
