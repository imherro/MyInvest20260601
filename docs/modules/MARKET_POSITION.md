# 市场仓位模块

本模块用于决定当前股票/ETF 权益总仓位。它不负责推荐具体股票，也不负责临时改写主线评级。

## 1. 模块目标

回答三个问题：

1. 当前权益仓位应该是多少？
2. 当前债券、短融、现金类仓位应该是多少？
3. 当前进攻仓应该放大、维持、收缩，还是暂停新增？

本模块输出的是组合层面的“仓位环境”，不是具体买卖清单。

## 2. 总公式

```text
市场机会分数 =
指数趋势20
+ 市场广度15
+ 成交量与流动性10
+ 资金流与风险偏好15
+ 主线强度15
+ 估值赔率15
+ 宏观政策环境10

市场仓位分数 = 市场机会分数 - 拥挤惩罚0~20
```

## 3. 仓位映射

| 市场仓位分数 | 市场状态 | 权益仓位 | 债券/现金仓位 |
| ---: | --- | ---: | ---: |
| 0-30 | 极弱/熊市 | 20%-30% | 70%-80% |
| 31-45 | 弱势震荡 | 30%-45% | 55%-70% |
| 46-60 | 中性修复 | 45%-60% | 40%-55% |
| 61-75 | 强势可进攻 | 60%-75% | 25%-40% |
| 76-85 | 高景气进攻期 | 70%-80% | 20%-30% |
| 86-100 | 强趋势且风险未失控 | 75%-85% | 15%-25% |

普通情况下权益仓位不超过 85%。

## 4. 评分细则

### 4.1 指数趋势 20 分

观察对象：

- 沪深300
- 中证500
- 中证1000
- 创业板指
- 科创50
- 上证指数作为辅助，不作为唯一依据

打分参考：

| 状态 | 分数 |
| --- | ---: |
| 多数指数在 20 日、60 日均线下方，趋势向下 | 0-5 |
| 指数横盘震荡，均线纠缠 | 6-10 |
| 主要指数站上 20 日线，但 60 日线未完全修复 | 11-15 |
| 多数指数站上 20 日、60 日线，趋势向上 | 16-20 |

注意：

- 不只看上证指数。
- 若指数上涨但创业板、科创、中小盘明显走弱，不能给高分。
- 若指数跌破关键趋势位，即使其他项较好，也要触发硬约束。

### 4.2 市场广度 15 分

观察对象：

- 上涨家数占比
- 涨跌中位数
- 创 20 日新高数量 vs 创 20 日新低数量
- 涨停数量 vs 跌停数量
- 强势板块数量

打分参考：

| 状态 | 分数 |
| --- | ---: |
| 上涨家数长期低于 40%，跌多涨少 | 0-4 |
| 上涨家数 40%-50%，局部机会 | 5-8 |
| 上涨家数 50%-60%，赚钱效应一般 | 9-11 |
| 上涨家数 60% 以上，赚钱效应明显 | 12-15 |

硬约束：

- 市场广度低于 45% 时，权益仓位不超过 60%。

### 4.3 成交量与流动性 10 分

观察对象：

- 两市成交额
- 成交额 / 20 日平均成交额
- 放量上涨、放量滞涨、缩量下跌、缩量反弹

打分参考：

| 状态 | 分数 |
| --- | ---: |
| 明显缩量，市场冷清 | 0-3 |
| 成交一般，未见明显增量 | 4-6 |
| 温和放量，配合上涨 | 7-8 |
| 持续放量且价格健康上行 | 9-10 |

注意：

- 爆量不一定是好事。
- 高位爆量滞涨应进入拥挤惩罚，而不是继续加分。

### 4.4 资金流与风险偏好 15 分

观察对象：

- 全 A 主力资金净流入/流出
- 主线行业资金净流入/流出
- 股票 ETF 净申购
- 宽基 ETF 资金流
- 行业 ETF 资金流
- ETF 成交额变化和份额变化
- 两融余额变化
- 北向/外资，如数据源可用
- 主动权益基金发行和申赎
- 人民币汇率和外部风险偏好
- 高股息、红利资产与成长资产的相对强弱

打分参考：

| 状态 | 分数 |
| --- | ---: |
| 资金持续流出，避险明显 | 0-4 |
| 资金中性，无明显方向 | 5-8 |
| 宽基或主线 ETF 有持续流入 | 9-12 |
| 权益资金明显回流，风险偏好提升 | 13-15 |

注意：

- 资金流要看持续性，不看单日异动。
- 宽基资金托底和主动风险偏好回升不是一回事，需要区分。
- 如果只使用 Tushare moneyflow 或单日净流入/净流出，必须说明这是资金流的部分代理，不足以单独确认风险偏好。
- ETF 份额、两融、北向/外资等数据缺失时，报告必须在“数据缺口”中披露，不能把缺失数据默认为中性。

### 4.5 主线强度 15 分

观察对象：

- 是否存在 1-2 条清晰主线
- 主线是否有 A 档评级
- 龙头是否强于指数
- 板块 ETF 是否趋势向上
- 板块内部是否扩散
- 是否有产业逻辑和业绩验证

打分参考：

| 状态 | 分数 |
| --- | ---: |
| 无主线，热点轮动快 | 0-4 |
| 有热点，但持续性差 | 5-8 |
| 有 1 条较清晰主线 | 9-12 |
| 有 1-2 条 A 级主线，资金持续强化 | 13-15 |

硬约束：

- 没有 A 级主线时，权益仓位不超过 65%。
- 主线强度低于 8 分时，进攻仓不超过股票仓的 25%。

### 4.6 估值赔率 15 分

观察对象：

- 沪深300 PE/PB 历史分位
- 中证500 PE/PB 历史分位
- 创业板、科创估值分位
- 股债性价比
- 主要主线行业估值分位
- 盈利预期是否上修
- 短期估值分位：约 60 个交易日
- 中期估值分位：约 1 年
- 长期估值分位：约 3 年/5 年

打分参考：

| 状态 | 分数 |
| --- | ---: |
| 估值高，赔率差 | 0-4 |
| 估值中性偏贵 | 5-8 |
| 估值中性或略便宜 | 9-11 |
| 估值低，股债性价比好 | 12-15 |

注意：

- 估值低不代表马上涨，但决定可承受的仓位上限。
- 主线估值过高时，即使大盘估值不贵，也不能给过高分。
- 60 日估值分位只能说明短期相对位置，不能替代 1 年、3 年或 5 年历史分位。
- 如果长期估值分位不可得，必须明确写“长期估值赔率待补充”，不能用 60 日分位直接推导长期便宜或长期昂贵。

### 4.7 宏观政策环境 10 分

观察对象：

- 货币政策
- 财政政策
- 地产政策
- 产业政策
- 监管态度
- 人民币汇率
- 利率方向
- 经济数据是否改善

打分参考：

| 状态 | 分数 |
| --- | ---: |
| 政策偏紧，风险事件多 | 0-3 |
| 政策中性，缺乏催化 | 4-6 |
| 政策边际转暖 | 7-8 |
| 政策明确支持权益或重点产业 | 9-10 |

注意：

- 政策不能替代市场事实。
- 政策利好必须观察趋势、资金和主线是否确认。

## 5. 拥挤惩罚 0-20 分

拥挤惩罚用于防止追在高潮区，已经从市场机会分数中扣除，不应再机械重复降仓。

观察对象：

- 指数连续大涨
- 成交额异常放大
- 龙头加速
- 主线成交占比过高
- 融资快速上升
- 散户情绪过热
- 高位放量滞涨
- 指数创新高但市场广度下降
- 主线内部开始掉队
- 估值分位过高

打分参考：

| 拥挤状态 | 惩罚 |
| --- | ---: |
| 无明显拥挤 | 0-3 |
| 局部偏热 | 4-7 |
| 主线明显拥挤 | 8-12 |
| 市场高潮，追涨风险高 | 13-16 |
| 疯狂阶段，随时可能剧烈回撤 | 17-20 |

操作限制：

| 拥挤惩罚 | 操作含义 |
| ---: | --- |
| 0-5 | 正常配置 |
| 6-10 | 可以持有，谨慎追涨 |
| 11-15 | 不提高总权益仓位，只做结构调整 |
| 16-20 | 不新增进攻仓，考虑减仓或切防御 |

## 6. 硬约束

硬约束优先于分数映射。

- 普通账户权益仓位上限：85%。
- 没有明确牛市主升浪证据：权益仓位不超过 75%。
- 没有 A 级主线：权益仓位不超过 65%。
- 市场广度低于 45%：权益仓位不超过 60%。
- 指数趋势低于 10 分：权益仓位不超过 60%。
- 主线强度低于 8 分：进攻仓不超过股票仓的 25%。
- 拥挤惩罚高于 15：不新增进攻仓。
- 单一行业/主线不超过权益仓位的 30%-35%。
- 主题仓不超过权益仓位的 10%。

## 7. 股票仓内部定义

股票仓内部建议必须先定义仓位角色，避免把同一 ETF 在核心仓、进攻仓和主题仓之间反复切换。

| 仓位类型 | 定义 | 典型对象 | 注意事项 |
| --- | --- | --- | --- |
| 核心仓 | 低换手、宽基或长期稳健暴露，用于承接主要权益仓位 | A500、沪深300、中证500、自由现金流、红利低波等 | 少量长期战略主线 ETF 可以纳入核心观察，但高弹性主题 ETF 默认不算核心仓 |
| 进攻仓 | 基于交易 A 档或强 B+ 主线的趋势进攻暴露 | AI、半导体、机器人等科技成长主线，或阶段性强势产业主线 | 必须引用主线研究的交易评级和阶段，不得仅凭长期逻辑加仓 |
| 防御仓 | 降低组合波动或对冲成长分歧的权益防御暴露 | 黄金、红利低波、公用事业、部分高股息能源等 | 正常区间可为权益仓的 7%-12%，是否取上沿取决于市场分歧和防御资产是否拥挤 |
| 主题仓 | 高弹性、低确定性、事件驱动或短期热点试错 | 商业航天、无人驾驶、短期事件型机器人分支等 | 不超过权益仓位 10%，且必须有退出条件 |

若一个方向同时具备长期战略价值和短期高波动属性，默认归入进攻仓或主题仓，而不是核心仓。例：AI、半导体一般归入进攻仓；只有在明确指定长期低换手 ETF 配置时，才可作为核心仓的少量卫星。

## 8. 触发式仓位调整

市场仓位报告必须给出下一步触发条件和对应仓位动作。触发条件不是预测，而是盘前、盘中、盘后模块可执行的条件表。

示例口径：

| 触发条件 | 仓位动作 |
| --- | --- |
| 沪深300、中证500、科创50等主要指数重新站上 20 日线，且成交额回到 20 日均值上方 | 权益上限可从当前区间上调 5 个百分点 |
| 交易 A 档主线扩散改善，半导体/AI 等代表 ETF 止跌或重新站上 20 日线 | 进攻仓可从低配恢复到中性，或提高 3-5 个百分点 |
| 主要指数继续破位，交易 A 档主线转弱，市场广度跌破 45% | 权益仓位上限下调到 45%-50% 或更低 |
| 成交继续萎缩，资金流代理指标持续流出 | 不提高权益仓位，优先保留债券/现金仓 |
| 防御/周期方向放量滞涨或快速拥挤 | 不追防御轮动，防御仓不再上调 |

实际报告应根据当日数据改写触发条件，不能机械复制示例。

## 9. 输出口径

每次输出必须包含：

- 日期和时段：盘前、盘中、盘后、周末
- 市场机会分数
- 拥挤惩罚
- 市场仓位分数
- 建议权益仓位区间
- 建议债券/现金仓位区间
- 股票仓内部建议：核心仓、进攻仓、防御仓、主题仓
- 股票仓内部定义是否沿用默认口径；如有调整，必须说明
- 触发式仓位调整表
- 触发的硬约束
- 今日操作含义
- 需要主线研究模块进一步确认的事项
- 数据缺口：资金流、ETF 份额、两融、北向/外资、长期估值分位等缺失情况

## 10. 与其他模块的关系

本模块可以使用主线研究模块的最新结论，但不能修改主线评级。

本模块输出后：

- 组合分析模块负责比较当前持仓与目标仓位的偏离。
- 操作建议模块负责决定具体买卖动作。
- 决策日志模块记录重要仓位变化和原因。

```text

必须输出总权益仓位建议、债券/现金仓位建议、股票仓内部结构、硬约束、触发式仓位调整表和数据缺口。
不要推荐具体股票，不要改写主线评级。
```
