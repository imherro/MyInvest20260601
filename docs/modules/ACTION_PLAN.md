# 操作建议模块

本模块用于基于前置研究成果，生成买入、加仓、减仓、卖出、持有、观察等操作建议。它不能绕过市场仓位、主线研究、ETF/个股档案和组合分析直接给出结论。

## 1. 模块目标

回答六个问题：

1. 今天是否需要操作？
2. 如果操作，操作哪个标的、什么方向、多少仓位？
3. 操作依据来自哪些前置研究？
4. 触发条件是什么？
5. 失效条件是什么？
6. 如果不操作，原因是什么？

操作建议必须可审查、可执行、可复盘。

## 2. 必须读取的前置结论

操作建议至少应读取：

- 最新市场仓位报告：决定总权益仓位边界。
- 最新主线登记册：决定进攻仓是否有方向。
- ETF 档案：决定 ETF 是否可以买、加、减、卖。
- 个股档案：决定个股是否可以买、加、减、卖。
- 最新组合分析：决定当前组合偏离和风险优先级。
- 决策日志：避免反复给出相互矛盾的建议。

如果缺少关键前置研究，操作建议必须先提示“需要补研究”，不能硬给买卖建议。

## 3. 操作类型

| 操作类型 | 含义 |
| --- | --- |
| Buy | 新建仓 |
| Add | 加仓已有持仓 |
| Hold | 继续持有 |
| Reduce | 减仓 |
| Sell | 卖出或清理 |
| Watch | 观察，等待条件 |
| NoAction | 不操作 |
| ResearchFirst | 先补研究 |

## 4. 建议强度

| 强度 | 含义 |
| --- | --- |
| Strong | 多个前置模块一致，风险可控 |
| Normal | 逻辑成立，但仍需控制仓位 |
| Weak | 仅小仓试错或等待确认 |
| Blocked | 关键条件缺失或触发硬约束 |

建议强度不等于仓位大小，仓位仍必须受总仓位、主线、组合和单标的上限约束。

## 5. 操作建议硬规则

- 不允许临时重写市场仓位分数。
- 不允许临时重写主线评级。
- 不允许给没有档案的大额 ETF/个股直接买入建议。
- 不允许给没有失效条件的买入或加仓建议。
- 不允许主题仓突破权益仓位 10%。
- 不允许单一行业/主线突破权益仓位 30%-35%。
- 不允许单一个股一般超过总资产 8%-12%。
- 拥挤惩罚高于 15 时，不新增进攻仓。
- 如果建议与前一日相反，必须解释变化原因。

## 6. 操作建议结构

每条建议必须包含：

- 操作类型
- 标的
- 仓位角色
- 当前仓位
- 建议仓位变化
- 目标仓位
- 建议强度
- 依据
- 触发条件
- 失效条件
- 风险
- 是否需要人工确认
- 复盘点

## 7. 不操作也要说明原因

不操作不是空结论。NoAction 必须说明属于哪一类：

- 市场仓位不支持新增。
- 主线不清晰。
- 标的未触发买入/加仓条件。
- 当前组合已经匹配目标。
- 风险或拥挤过高。
- 需要先补研究。
- 等待盘中/盘后确认。

## 8. 盘前、盘中、盘后边界

### 盘前

可以制定计划：

- 今天是否需要调整总仓位。
- 哪些标的是候选操作。
- 哪些条件触发后才执行。
- 哪些标的不应操作。

### 盘中

只检查触发条件：

- 是否触发买入、加仓、减仓、卖出条件。
- 是否仍符合市场仓位和主线约束。
- 是否需要人工确认。

盘中不得临时发明新主线或新策略。

### 盘后

记录：

- 建议是否执行。
- 执行是否符合计划。
- 未执行原因。
- 需要复盘的偏差。

## 9. 输出优先级

优先处理：

1. 违反硬约束的风险。
2. 市场仓位和实际仓位明显冲突。
3. 主线降级但仍作为进攻仓持有。
4. 单一主线、行业、个股过度集中。
5. 已触发失效条件的 ETF/个股。
6. 符合加仓条件且组合低配的高质量标的。

暂缓处理：

- 缺少档案的标的。
- 条件未触发的观察标的。
- 小幅偏离但没有风险的仓位。

## 10. 输出口径

每次操作建议必须包含：

- 日期和时段
- 读取的来源文件
- 总体结论
- 操作清单
- 不操作清单
- 需要补研究清单
- 风险和硬约束
- 盘中触发条件
- 决策日志条目

## 11. 与其他模块的关系

- 市场仓位模块决定总仓位边界。
- 主线研究模块决定进攻仓方向。
- ETF/个股研究模块决定标的自身评级和操作条件。
- 组合分析模块决定偏离和优先级。
- 决策日志模块记录本次建议和后续执行。
- 盘中提醒模块只监控本模块定义的触发条件。

## 12. 使用提示词

日常使用时，可以对 Codex 说：

```text
请按 docs/modules/ACTION_PLAN.md 和 templates/action_plan_template.md 生成今日操作建议。
必须引用最新市场仓位、主线、ETF、个股和组合分析结论。
不要临时重写前置研究结论。
如果缺少关键研究，输出 ResearchFirst，而不是硬给买卖建议。
```
