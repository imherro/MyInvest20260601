# 主线研究模块

本模块用于判断 A 股当前主线、主线等级和变化原因。它是进攻仓配置的依据，但不直接给出具体买卖指令。

## 1. 模块目标

回答六个问题：

1. 当前 A 股有哪些主线？
2. 哪些主线是 A 档、B 档、C 档、D 档？
3. 哪些方向可以进入进攻仓？
4. 哪些方向只能作为主题仓试错？
5. 每条主线处于什么周期阶段，大致从什么时候开始，当前阶段可能持续到什么时候？
6. 本次主线结论相比上次发生了什么变化，为什么？

主线研究必须先固化，再被市场仓位、ETF、个股、组合和操作建议模块引用。

## 2. 主线评级

| 评级 | 定义 | 仓位含义 |
| --- | --- | --- |
| A 档 | 主仓方向，具备产业逻辑、资金确认、趋势确认和扩散能力 | 可进入进攻仓核心 |
| B 档 | 副线方向，逻辑成立但强度、持续性或资金确认不足 | 可低配或观察，不作为主攻 |
| C 档 | 主题方向，弹性大但持续性不确定 | 只能进入主题仓试错 |
| D 档 | 观察或回避，缺乏趋势或风险收益不佳 | 不配置或仅观察 |

原则：

- A 档最多 1-2 条。
- C 档不能因为短期暴涨直接升级为 A 档。
- 没有 A 档主线时，市场仓位模块中的权益仓位上限不超过 65%。

## 3. 主线周期阶段

主线评级回答“强不强”，周期阶段回答“走到哪了”。同样是 A 档，启动期 A 和高潮期 A 的操作含义完全不同。

| 阶段 | 定义 | 操作含义 |
| --- | --- | --- |
| 萌芽 | 有催化和局部异动，但趋势、资金、扩散尚未确认 | 只观察，不作为进攻仓 |
| 启动 | 龙头和 ETF 开始转强，资金初步流入 | 可小仓试探或列入重点观察 |
| 确认 | 趋势、资金、扩散至少两项确认 | 可进入进攻仓候选 |
| 加速 | 主线持续强化，龙头和中军共振 | 可作为进攻仓核心，但需警惕拥挤 |
| 高潮 | 成交、讨论度、涨幅和情绪明显过热 | 不宜新增，优先保护利润 |
| 分歧 | 龙头分化、补涨混乱或放量滞涨 | 降低新增，等待方向选择 |
| 退潮 | 趋势破坏、资金流出、扩散失败 | 降级或移出，减少暴露 |
| 修复 | 退潮后重新企稳，但尚未重新确认 | 观察是否重新进入确认阶段 |

每条主线必须记录：

- 主线首次进入观察的日期。
- 主线首次确认的日期。
- 当前阶段。
- 当前阶段开始日期。
- 预估有效窗口。
- 下一次阶段复核日期。
- 阶段失效条件。

注意：

- 起止时间是研究假设，不是精确预测。
- 如果无法判断起点，必须写“待确认”，不能编造日期。
- 周期阶段变化必须写入变化记录。

## 4. 主线评分框架

每条主线按 100 分评分：

```text
产业逻辑20
+ 政策/景气催化15
+ 资金参与20
+ 趋势强度20
+ 板块扩散15
+ 业绩验证10
- 拥挤风险0~20
```

最终主线分数：

```text
主线分数 = 基础分 - 拥挤风险
```

评级参考：

| 主线分数 | 建议评级 |
| ---: | --- |
| 80-100 | A 档候选 |
| 65-79 | B 档 |
| 50-64 | C 档 |
| 0-49 | D 档 |

注意：

- 分数只是辅助，评级必须结合定性判断。
- 80 分以上不自动成为 A 档，还要满足 A 档硬条件。
- 高拥挤主线可以维持 A 档，但不一定允许新增进攻仓。

## 5. 分项评分细则

### 5.1 产业逻辑 20 分

观察对象：

- 是否处于长期产业趋势中
- 是否有真实需求或供给约束
- 是否存在技术迭代、国产替代、全球周期或商业模式变化
- 是否不是纯概念炒作

打分参考：

| 状态 | 分数 |
| --- | ---: |
| 概念为主，产业逻辑弱 | 0-5 |
| 有逻辑但验证不足 | 6-10 |
| 产业逻辑清晰，部分验证 | 11-15 |
| 长期逻辑强，需求、供给或技术趋势明确 | 16-20 |

### 5.2 政策/景气催化 15 分

观察对象：

- 国家政策支持
- 产业政策落地
- 行业景气改善
- 价格、订单、招标、产能利用率等景气指标

打分参考：

| 状态 | 分数 |
| --- | ---: |
| 无明显催化或政策压制 | 0-4 |
| 有零散催化，但持续性弱 | 5-8 |
| 政策或景气边际改善 | 9-12 |
| 政策和景气共振 | 13-15 |

### 5.3 资金参与 20 分

观察对象：

- 板块成交额占比
- 行业 ETF 资金流
- 主动资金参与痕迹
- 龙头成交和换手
- 资金是否持续流入而非一日游

打分参考：

| 状态 | 分数 |
| --- | ---: |
| 资金参与弱，成交低迷 | 0-5 |
| 有短期资金，但持续性差 | 6-10 |
| 资金持续流入，成交温和放大 | 11-15 |
| 机构和趋势资金共同参与，持续强化 | 16-20 |

### 5.4 趋势强度 20 分

观察对象：

- 板块指数或 ETF 是否站上 20 日、60 日均线
- 龙头是否强于指数
- 是否持续新高或回撤可控
- 板块相对沪深300、中证500是否有超额收益

打分参考：

| 状态 | 分数 |
| --- | ---: |
| 趋势向下 | 0-5 |
| 横盘震荡，方向不明 | 6-10 |
| 趋势修复，强于大盘 | 11-15 |
| 趋势向上，龙头持续强势 | 16-20 |

### 5.5 板块扩散 15 分

观察对象：

- 是否只有少数龙头上涨
- 中军、弹性股、补涨股是否形成梯队
- ETF 成分股上涨家数
- 细分方向是否扩散

打分参考：

| 状态 | 分数 |
| --- | ---: |
| 只有少数个股表现 | 0-4 |
| 局部扩散，结构不完整 | 5-8 |
| 龙头、中军、补涨有一定梯队 | 9-12 |
| 板块内部扩散充分，赚钱效应稳定 | 13-15 |

### 5.6 业绩验证 10 分

观察对象：

- 财报是否验证景气
- 盈利预期是否上修
- 订单、价格、出货、毛利率是否改善
- 是否只是远期故事，没有业绩支撑

打分参考：

| 状态 | 分数 |
| --- | ---: |
| 无业绩支撑或业绩下修 | 0-3 |
| 业绩验证不足 | 4-6 |
| 部分公司开始验证 | 7-8 |
| 板块整体业绩趋势明确改善 | 9-10 |

## 6. 拥挤风险 0-20 分

拥挤风险用于防止把高潮期误判为可加仓期。

观察对象：

- 龙头加速大涨
- 板块连续大阳
- 成交额占比异常抬升
- ETF 放量滞涨
- 板块内部开始掉队
- 补涨股乱飞但中军走弱
- 估值分位过高
- 市场讨论热度过高

打分参考：

| 拥挤状态 | 扣分 |
| --- | ---: |
| 无明显拥挤 | 0-3 |
| 局部偏热 | 4-7 |
| 明显拥挤，追涨风险上升 | 8-12 |
| 高潮阶段，不适合新增 | 13-16 |
| 疯狂阶段，优先保护利润 | 17-20 |

操作含义：

| 拥挤风险 | 操作含义 |
| ---: | --- |
| 0-5 | 可按评级正常配置 |
| 6-10 | 可持有，谨慎追涨 |
| 11-15 | 不新增主线仓位，只做结构调整 |
| 16-20 | 优先考虑减仓或等待回撤确认 |

## 7. A 档硬条件

一条主线要成为 A 档，通常需要同时满足：

- 产业逻辑清晰，不是纯概念。
- 政策、景气或技术趋势至少有一项强支撑。
- 板块 ETF 或指数趋势向上。
- 龙头强于指数并持续体现超额收益。
- 板块内部有扩散，不只是少数个股。
- 资金参与具备持续性。
- 至少持续 5-10 个交易日。
- 拥挤风险没有高到禁止新增，或虽拥挤但仍可维持已有仓位。

## 8. 升级、降级、移出规则

变化类型：

- 维持：评级不变。
- 上调：评级提升，例如 B → A。
- 下调：评级降低，例如 A → B。
- 新增：新进入主线登记册。
- 移出：从当前主线池移出，仅保留历史记录。

上调条件：

- 分数提升并持续确认。
- 资金、趋势、扩散至少两项改善。
- 有新的产业、政策、景气或业绩证据。

降级条件：

- 龙头明显走弱。
- 板块 ETF 跌破关键趋势。
- 资金持续流出。
- 板块扩散失败，只剩少数个股。
- 产业逻辑被证伪或业绩不及预期。
- 拥挤后高位放量滞涨。
- 主线周期从加速/确认转入分歧或退潮，且资金、趋势或扩散同步走弱。

移出条件：

- 连续两次更新处于 D 档。
- 产业逻辑被证伪。
- 资金和趋势均明显转弱。
- 已不再影响进攻仓和主题仓配置。

## 9. 输出口径

每次输出必须包含：

- 日期和时段
- 本次主线总览
- A/B/C/D 档列表
- 每条主线周期阶段、首次确认日期、当前阶段起始日期、预估有效窗口
- 每条主线分项评分
- 本次变化：维持、上调、下调、新增、移出
- 变化原因
- 对市场仓位模块的影响
- 对 ETF/个股研究模块的影响
- 下次观察条件

## 10. 与其他模块的关系

本模块输出后：

- 市场仓位模块引用“是否存在 A 档主线”和“主线强度”。
- ETF 研究模块引用主线评级决定 ETF 角色。
- 个股研究模块引用所属主线，但不能忽视个股自身估值和风险。
- 操作建议模块只能基于已保存的主线评级给出动作，不能临时改写评级。

## 11. 使用提示词

日常使用时，可以对 Codex 说：

```text
请按 docs/modules/THEME_RESEARCH.md 和 templates/theme_review_template.md 更新本周主线研究。
必须读取 research/themes/theme_registry.json 中的上次结论。
只允许输出主线评级、变化原因和对仓位的影响，不要直接给具体买卖指令。
```
