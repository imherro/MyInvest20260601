# 组合分析模块

本模块用于判断当前持仓是否匹配市场仓位、主线评级、ETF/个股档案和风险约束。它负责发现偏离和风险，不直接生成最终买卖指令。

## 1. 模块目标

回答七个问题：

1. 当前总权益仓位是否匹配市场仓位模块的建议？
2. 债券、短融、现金仓位是否足够？
3. 核心仓、进攻仓、防御仓、主题仓比例是否合理？
4. 单一主线、行业、个股或 ETF 是否过度集中？
5. 当前持仓是否与主线、ETF、个股档案一致？
6. 哪些仓位需要优先处理？
7. 哪些持仓不建议操作，只需要观察？

组合分析输出的是“偏离诊断”和“调整方向”，不是具体交易清单。

## 2. 输入文件

组合分析必须尽量引用以下文件：

- 最新市场仓位报告：`research/market/`
- 最新主线登记册：`research/themes/theme_registry.json`
- ETF 登记册和 ETF 档案：`research/etfs/`
- 个股登记册和个股档案：`research/stocks/`
- 当前持仓快照：`research/portfolio/`
- 决策日志：`research/logs/decision_log.md`

如果缺少关键输入，必须明确写出“无法判断”的部分，不能假装完整。

## 3. 组合分层

组合按总资产分为：

- 权益仓：股票、股票型 ETF、跨境权益 ETF。
- 债券/现金仓：货币、短融、中短债、现金等。

权益仓内部再分为：

- 核心仓：宽基和长期基础配置。
- 进攻仓：A 档主线相关 ETF/个股。
- 防御仓：黄金、红利低波、公用事业、银行、消费、医药等。
- 主题仓：机器人、商业航天、无人驾驶等试错仓。

## 4. 基准约束

组合分析必须检查：

- 普通账户权益仓位上限：85%。
- 没有明确牛市主升浪证据：权益仓位不超过 75%。
- 没有 A 级主线：权益仓位不超过 65%。
- 市场广度低于 45%：权益仓位不超过 60%。
- 指数趋势低于 10 分：权益仓位不超过 60%。
- 主线强度低于 8 分：进攻仓不超过股票仓的 25%。
- 拥挤惩罚高于 15：不新增进攻仓。
- 单一行业/主线不超过权益仓位的 30%-35%。
- 主题仓不超过权益仓位的 10%。
- 单一个股一般不超过总资产的 8%-12%。

硬约束优先于组合偏好。

## 5. 偏离类型

| 偏离类型 | 说明 |
| --- | --- |
| under_allocated | 实际仓位低于建议区间 |
| over_allocated | 实际仓位高于建议区间 |
| concentration_risk | 单一标的、行业或主线过度集中 |
| style_imbalance | 风格过度偏向成长、价值、红利、周期等 |
| stale_position | 持仓逻辑过期，缺少最新研究支持 |
| missing_profile | 持仓没有 ETF 或个股档案 |
| conflict_with_theme | 持仓与主线评级冲突 |
| conflict_with_market_position | 持仓与市场仓位建议冲突 |
| no_action_needed | 无需调整 |

## 6. 优先级规则

优先处理：

1. 违反硬约束的仓位。
2. 没有研究档案的大额持仓。
3. 主线已降级但仍作为进攻仓持有的仓位。
4. 单一行业/主线集中度超标。
5. 单一个股仓位超标。
6. 与市场仓位建议明显冲突的总仓位。

暂缓处理：

- 小幅偏离目标仓位但不触发硬约束。
- 仍符合档案条件且无明显风险的持仓。
- 市场波动造成的短期被动偏离。

## 7. 输出口径

每次组合分析必须包含：

- 日期和时段
- 当前总资产结构
- 当前权益仓位和目标权益仓位
- 当前债券/现金仓位和目标债券/现金仓位
- 权益仓内部结构
- 持仓明细和角色分类
- 偏离诊断
- 风险集中度
- 缺失研究档案清单
- 优先处理项
- 不建议操作项
- 需要交给操作建议模块处理的问题

## 8. 与操作建议模块的边界

组合分析可以说：

- “当前进攻仓高于目标，需要降低。”
- “某主线仓位超过上限，需要操作建议模块制定减仓方案。”
- “某 ETF 缺少档案，先补研究。”

组合分析不直接说：

- “今天买入某 ETF 多少。”
- “今天卖出某股票多少。”
- “盘中触发某价格就下单。”

具体动作由操作建议模块在读取组合分析后生成。

## 9. 当前持仓快照

组合分析依赖持仓快照。持仓快照至少需要：

- 日期
- 账户总资产
- 现金/债券/短融金额和比例
- 每个股票/ETF 的代码、名称、数量、市值、成本、盈亏、仓位比例
- 每个标的的仓位角色
- 是否已有档案

如果用户不想记录真实金额，可以使用百分比和脱敏金额区间。

## 10. 使用提示词

日常使用时，可以对 Codex 说：

```text
请按 docs/modules/PORTFOLIO_ANALYSIS.md 和 templates/portfolio_snapshot_template.md 分析当前组合。
必须引用最新市场仓位、主线登记册、ETF 登记册和个股登记册。
只输出组合偏离、风险和需要操作建议模块处理的问题，不直接给最终买卖指令。
```
